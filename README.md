# TrekIt V2

TrekIt is a private, cross-platform adventure journal for capturing trips and
sharing memories with trusted friends and family.

## Technology

- Flutter for iOS, Android, and web
- Firebase Authentication
- Cloud Firestore
- Cloud Storage for Firebase
- Firebase Hosting for the web app

The Firebase project is `trekit-10e88`.

## Local development

```sh
flutter pub get
flutter run
```

Run the project checks with:

```sh
flutter analyze
flutter test
```
